# Support

Porticle is a community-maintained open-source project. Before opening an issue, search existing
issues and review the troubleshooting notes in the README.

- Use the bug report form for reproducible defects and include only redacted process details.
- Use the feature form for focused proposals that preserve Porticle's local, tray-first scope.
- Report vulnerabilities privately through GitHub's security advisory flow as described in
  [SECURITY.md](SECURITY.md).

Public issues are not a private support channel and response times are not guaranteed. Never attach
credentials, signing material, private commands, or personal paths.

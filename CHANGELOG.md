# Changelog

All notable changes to Porticle are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Initial tray-first macOS and Windows application.
- TCP and UDP discovery across IPv4 and IPv6.
- Process PID, command, address, protocol, service recognition, and localhost URLs.
- Search, protocol filters, keyboard navigation, copy/open actions, and automatic refresh.
- Watched ports with inactive state and ownership notifications.
- Identity-bound graceful process-tree termination with configurable force fallback.
- Explicit protected-process, permission-denied, stale-owner, and reopened-port results.
- System, light, and dark themes with customizable signal color.
- Launch-at-login, kill confirmation, refresh cadence, notifications, and global shortcut settings.
- Sandboxed renderer, typed preload API, strict validated IPC, CSP, custom protocol, ASAR integrity, and Electron fuses.
- Unit, component, and browser workflow tests.
- macOS DMG/ZIP and Windows NSIS packaging plus tag-driven signed release automation.
- Complete open-source documentation, issue forms, pull request template, CI, CodeQL, and dependency updates.
- Signed in-app update checks with explicit download, progress, and restart-to-install controls.
- Atomic multi-platform releases with updater manifests, blockmaps, SHA-256 checksums, CycloneDX
  SBOMs, and artifact provenance attestations.
- Adaptive background port scanning and a production renderer size budget.
